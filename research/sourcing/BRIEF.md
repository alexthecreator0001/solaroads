# Sourcing brief (shared)

PROJECT CONTEXT (read carefully):
We are producing a ~14.5-15 s vertical video ad (1080x1920, 60 fps) for SOLARO (https://solaro.sk), a Slovak company that sells and installs solar photovoltaic systems.
Story: the evolution of electricity — from the first stone/flint spark, to fire, lightning, early electrical experiments, the light bulb / electric age, the grid — to the SUN and SOLAR panels — ending on the Solaro logo.
Creative direction: bold, LIGHT MODE (pure white background), clean and precise — NO beige/sepia/"artsy vintage" look, no eyebrow labels. Black-and-white imagery (engravings, sculptures, archival photos, modern photos) cut out cleanly on white, with Solaro-orange vector elements (#FF3D00 -> #FF5E2B gradient, the brand colour) painted/animated on top. Very fast-paced (cuts every 0.1-0.4 s), morphing text, Solaro-mark SVG animations, clean 3D, zooms, several images at once.
Reference video (style/timing inspiration only — we will NOT copy it): /home/user/solaroads/research/reference/reference.mp4 — Anthropic's "Claude — Keep thinking" spot (1080x1920, 60 fps, 14.47 s, white bg, B&W engravings/sculptures, terracotta paint-on marks, letter-swap text morphs ask->task, draft->craft, think->Keep thinking., 3D asterisk, ends on Claude logo).
Brand assets: /home/user/solaroads/assets/solaro-mark.svg (4-shape mark: ring top-left, quarter-rounded square top-right, quarter-rounded square bottom-left, teardrop/pin shape with hole bottom-right; orange vertical gradient #FF5E2B->#FF3D00, subtle inner shadows) and /home/user/solaroads/assets/solaro-logo.svg (mark + "Solaro" wordmark in #1C1C1C, heavy geometric sans).
Repo root: /home/user/solaroads (git repo; do NOT commit or push — the orchestrator will). assets/raw/ is git-ignored (fine for big downloads). Put small, reviewable outputs (markdown, contact sheets <1.5 MB each) under research/.
Tools available: ffmpeg/ffprobe, python3 (numpy, Pillow; you may 'pip install --break-system-packages <pkg>' e.g. opencv-python-headless, scipy, librosa), node 22 + npm, ImageMagick 'convert', Playwright + Chromium (PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers, never run 'playwright install').
NETWORK NOTES: outbound HTTPS goes through a proxy (CA bundle /root/.ccr/ca-bundle.crt is preconfigured). Always send a User-Agent like "SolaroAdResearch/1.0 (https://solaro.sk)".
 - Wikimedia (commons API and upload.wikimedia.org) currently returns HTTP 429 (rate limited) — you may try it sparingly with long backoff (30-90 s) but do not depend on it.
 - WORKING sources: Wellcome Collection API (https://api.wellcomecollection.org/catalogue/v2/images?query=...  — check each image's license: pdm/cc-0/cc-by are OK), Smithsonian Open Access (https://api.si.edu/openaccess/api/v1.0/search?q=...&api_key=DEMO_KEY — keep only CC0 media), Europeana (https://api.europeana.eu/record/v2/search.json?wskey=api2demo&reusability=open&query=...), Openverse (https://api.openverse.org/v1/images/?q=...&license_type=commercial — note: excludes NC; still check for SA/ND), Internet Archive (archive.org advancedsearch + IIIF/download), NASA (https://images-api.nasa.gov/search?q=... — NASA imagery is public domain), Library of Congress (https://www.loc.gov/pictures/search/?q=...&fo=json and https://www.loc.gov/photos/?q=...&fo=json — check rights 'No known restrictions'), Cleveland Museum of Art open access (https://openaccess-api.clevelandart.org/api/artworks/?q=...&cc0=1&has_image=1), oldbookillustrations.com (public domain scans), Flickr public feeds (license unclear — avoid unless Openverse confirms), images.unsplash.com direct image URLs (Unsplash search pages are bot-protected), huggingface.co (models/datasets).
 - BLOCKED: pexels, pixabay, rawpixel, picryl, publicdomainpictures, github.com release pages (raw.githubusercontent.com works).
LICENSE RULES for any downloaded image: allowed = public domain / PDM / CC0 / US-government works / CC-BY (record attribution) / Unsplash License. Avoid NC, ND and SA. Record every downloaded file in a credits.json in its folder: [{"file","title","creator","date","source_url","license","notes"}].


SOURCING GOALS — what makes an image useful for THIS ad:
 - High resolution: long side >= 1600 px preferred (>= 1200 px minimum). Fetch the largest available rendition (IIIF full/max, original file).
 - Must survive conversion to clean black-and-white on PURE WHITE: line engravings/etchings/woodcuts/patent drawings on light paper (we will level the paper to #FFFFFF), objects photographed on plain/white/black backgrounds (we will cut them out), strong silhouettes, crisp sculptures. Avoid busy full-bleed scenes unless iconic (they can still work as rectangular 'cards').
 - Variety of SCALE and TYPE: hero single objects (for big centered shots), several small related objects (for grids/collages of 3-12 like the reference's snowflake grid), hands/human gestures (sculpture hands, hands holding tools), diagrams/scientific apparatus (to paint orange lines over), textures (e.g. sparks, filaments, solar cell grid) and a few iconic 'aha' images everyone recognises.
 - Prefer motifs whose SHAPE can be matched to the Solaro mark shapes (circles/rings = sun, bulb, coil end-on; quarter-rounded squares; teardrop = flame/drop/bulb) or to each other (match-cuts: spark -> star -> sun; flame -> bulb; lightning bolt -> filament -> power line).
 - Download 20-40 strong candidates for your era (quality over quantity, but give the art director real choice). Name files descriptively: <era>-<subject>-<source>.jpg (lowercase, hyphens).
 - After downloading, make a labelled contact sheet (ImageMagick montage or PIL; thumbnails ~300 px with filename labels) saved to /home/user/solaroads/research/sourcing/<era>-contact.jpg (keep under 1.5 MB; split into -1/-2 if needed) and LOOK at it yourself (Read the image) to drop weak picks.
 - Write /home/user/solaroads/research/sourcing/<era>.md: a table of every kept file with subject, size (px), license, why it's useful, suggested treatment (engraving-clean / cutout / card / texture) and match-cut ideas. Flag the top 8 picks.
